## 🚀 كيفية تشغيل البرنامج

### الطريقة الأولى: نسخة سطح المكتب مع التنبيهات العائمة الحقيقية
انقر نقراً مزدوجاً على الملف:
```
تشغيل_البرنامج_سطح_المكتب.bat
```
أو عبر الطرفية:
```bash
npm run desktop
```
* سيعمل البرنامج في نافذة سطح مكتب مستقلة، وعند إغلاقه يستمر في العمل في شريط المهام (System Tray) لإظهار التنبيهات العائمة كل 30/60/90 دقيقة.

### الطريقة الثانية: نسخة المتصفح (Web Localhost)
انقر نقراً مزدوجاً على الملف:
```
تشغيل_نسخة_المتصفح.bat
```
أو عبر الطرفية:
```bash
npm start
```
ثم افتح الرابط في أي متصفح:
`http://localhost:4500`
